DIALOGUE EDITOR TEXT FIELDS - PART 7
====================================

New controls
------------
FIELD>
    Cycles through editable text fields:

    - Quest ID
    - Quest Title
    - Quest Summary
    - Node Text
    - Choice ID
    - Choice Text
    - Objective ID
    - Objective Text
    - Condition Reference

EDIT
    Copies the selected field into the editor input buffer and starts
    normal SDL text input.

APPLY
    Writes the input buffer back into the selected JSON field, saves the
    JSON file, and reloads the preview.

Condition Reference behavior
----------------------------
The field automatically edits the correct member for the selected
condition type:

    has_item                         -> item
    quest state / quest_stage        -> quest
    objective conditions             -> objective
    world/npc flag or variable       -> id

IDs are normalized using the same lowercase ID rules as the runtime.
Dialogue text, titles, and summaries preserve spaces and punctuation.

Input behavior
--------------
- Backspace works through the editor's existing text-input event code.
- Ctrl+C and Ctrl+V use the existing editor clipboard behavior.
- The active text and blinking cursor are shown on the third toolbar row.
- APPLY immediately saves the JSON.

Current limitation
------------------
This part handles text fields. Numeric fields such as item count, gold,
stage, target, map X/Y, and variable values are the next development
bit.

Formatting
----------
Actual C++ tabs are allowed.
Visible backslash-plus-t sequences: 0
Lexical brace balance: passed
