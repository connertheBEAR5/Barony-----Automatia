DYNAMIC QUEST GIVER + DIALOGUE RECRUITMENT - PART 4
====================================================

Dynamic giver marker
--------------------
Use this in quest.origin:

    "track_npc": true,
    "npc_persistent_id": 125

The runtime resolves that persistent ID against the live monster on the
origin map whenever journal/minimap data is built. The solid yellow
giver marker follows the NPC's current tile.

The marker is hidden when:
- the NPC is not present on the active map,
- the NPC is dead/removed,
- the NPC has already become a follower.

Static origin x/y markers still work.

Dialogue recruitment
--------------------
Use this inside a choice action:

    "recruit_npc": true

The host validates the pending dialogue NPC and calls Barony's existing
forceFollower() path. After success it sets this persistent NPC flag:

    recruited = true

That flag can be used by later dialogue conditions to hide or redirect
recruitment dialogue.

Editor foundation
-----------------
The dialogue browser now reports:
- Static tile vs Follow NPC giver marker
- tracked persistent ID
- number of recruit_npc actions

The full editable form controls are still the next UI-focused part.
