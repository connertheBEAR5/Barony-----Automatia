BARONY AUTOMATIA - WINDOWS DISTRIBUTION DEPENDENCY AND LICENSE GUIDE
===================================================================

Scope
-----

This document records the native Windows x64 OpenAL release package design.
It is an engineering compliance record, not legal advice or a grant of any
redistribution right. Consult the applicable agreements before publishing.

The package script copies no DLL from System32, SysWOW64, PATH, another game,
or a DLL download site. It stages only the PE dependency closure from the
configured sources and rejects unknown third-party DLLs.


Current audited dependency set
------------------------------

The exact package output is authoritative: see THIRD_PARTY_MANIFEST.json for
per-file SHA-256 values and THIRD_PARTY_NOTICES.txt for the generated index.
The current x64-windows build used these vcpkg ports:

    OpenAL Soft     1.25.1#2      OpenAL32.dll
    SDL2            2.32.10#1    SDL2.dll
    SDL2_image      2.8.12       SDL2_image.dll
    SDL2_net        2.2.0#3      SDL2_net.dll
    SDL2_ttf        2.24.0       SDL2_ttf.dll
    libogg          1.3.6#1      ogg.dll
    libvorbis       1.3.7#4      vorbis.dll, vorbisfile.dll
    GLEW            2.3.1        glew32.dll
    FreeType        2.14.3       freetype.dll
    libpng          1.6.58       libpng16.dll
    zlib            1.3.2#1      z.dll
    bzip2           1.0.8#6      bz2.dll
    Brotli          1.2.0        brotlicommon.dll, brotlidec.dll
    fmt             12.2.0       fmt.dll (OpenAL Soft runtime dependency)

Steamworks uses steam_api64.dll only from the authorized Steamworks SDK 1.65
redistributable directory. No other SDK content is staged. Steamworks
redistribution remains subject to the distributor's Steamworks agreement.

PhysicsFS is a locally built, modified 3.2.0 runtime. The modification is a
Windows profile-path fallback: when GetUserProfileDirectoryW supplies no path
in a restricted environment, it falls back to USERPROFILE. The package marks
this binary Modified=true, copies its exact license, and includes the complete
modified source tree in third_party_source.


License material included in every staged package
-------------------------------------------------

The stager copies the exact installed vcpkg copyright material rather than
paraphrasing it. Expected locations are:

    licenses\OpenAL-Soft\copyright
    licenses\SDL2\copyright
    licenses\SDL2_image\copyright
    licenses\SDL2_net\copyright
    licenses\SDL2_ttf\copyright
    licenses\libogg\copyright
    licenses\libvorbis\copyright
    licenses\PhysicsFS\LICENSE.txt
    licenses\GLEW\copyright
    licenses\FreeType\copyright
    licenses\libpng\copyright
    licenses\zlib\copyright
    licenses\bzip2\copyright
    licenses\Brotli\copyright
    licenses\fmt\copyright

OpenAL Soft is dynamically linked as OpenAL32.dll. Its exact vcpkg license
material includes the applicable LGPL text and PFFFT/FFTPACK notice. The
package also includes the exact source archive used for the OpenAL Soft port:

    third_party_source\openal-soft-<version>.tar.gz

OpenAL Soft is not modified by this package. Dynamic linking plus corresponding
source/license material is the package's conservative LGPL-oriented approach;
obtain legal review for any public distribution.

The single-file side-by-side installer embeds this same material. During
installation it places it under the Automatia game folder as
automatia_licenses and automatia_third_party_source; it is not fetched from
Git or a third-party DLL download site at player install time.

For FreeType, this package records the FreeType License option, not an
unnecessary GPL selection. GLEW's full upstream multi-notice text is preserved
in its copied copyright file. SDL family, libpng, zlib, bzip2, Brotli, Ogg,
Vorbis, and fmt notices are likewise copied from their exact installed ports.


MSVC runtime deployment
------------------------

The MSVC-built executables import MSVCP140.dll, VCRUNTIME140.dll,
VCRUNTIME140_1.dll, and UCRT API-set DLLs. The package does not copy these
from Windows. Instead it stages:

    prerequisites\VC_redist.x64.exe

That file must be the official x64 redistributable from the installed Visual
Studio Redist/MSVC directory that matches or is newer than the compiler used
to build the release. The manifest records its checksum and provenance.


Validator policy
----------------

tools\package_windows_release.py validates the PE dependency graph for
barony.exe, editor.exe when included, and every bundled DLL. It classifies:

* Windows system imports: not bundled.
* MSVC runtime imports: satisfied by the official VC_redist prerequisite.
* Project/runtime imports: bundled only from the configured audited source.
* Unknown imports: packaging failure.

It additionally rejects FMOD, missing OpenAL32.dll, missing OpenAL source,
missing licenses, checksum mismatches, non-x64 PE files, duplicate names,
unresolved dependencies, unconfigured Steamworks provenance, and an unmarked
patched PhysicsFS binary.


Manual review still required
----------------------------

* Confirm the distributor's Steamworks SDK agreement permits the intended
  steam_api64.dll redistribution.
* Confirm rights to distribute Barony game assets, DLC assets, Steam content,
  and any third-party mods. Dependency DLL rights are separate from game asset
  rights.
* Perform interactive smoke tests from the staged folder on a clean Windows
  test machine. In particular confirm Steam initialization, --nosteam,
  main-menu music, UI/gameplay/positional/ambient audio, volume controls, and
  clean shutdown.
* Re-run the package script after changing a vcpkg port, Steamworks SDK,
  OpenAL source archive, compiler, or patched PhysicsFS source. The old
  manifest must not be reused for a new binary.
