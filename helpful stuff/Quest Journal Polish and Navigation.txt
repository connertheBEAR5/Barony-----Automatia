QUEST JOURNAL POLISH AND NAVIGATION
=====================================

Visual changes
--------------
- Uses Barony character-sheet tooltip borders as nine-slice panels.
- Uses the follower-wheel banner for the journal title.
- Uses original character-sheet buttons for tabs and quest entries.
- Uses the original Alchemy close button artwork.
- Separates the quest list and detail area into framed panels.
- Uses Barony's character-sheet neutral and gold text colors.
- Highlights the selected tab and quest with pressed-button artwork.

Mouse/camera behavior
---------------------
Opening the journal from gameplay now calls Player::openStatusScreen().

That uses Barony's native UI path to:
- disable shoot mode,
- release relative mouse input,
- show/free the cursor,
- prevent camera movement.

Closing the journal restores shoot mode through:
Player::closeAllGUIs(CLOSEGUI_ENABLE_SHOOTMODE, CLOSEGUI_CLOSE_ALL)

When the journal is opened while another inventory screen is already
open, closing it only closes the journal overlay and leaves the existing
inventory state alone.

Navigation
----------
J
    Open/close journal.

Escape
    Close journal.

Left/Right
    Change Active/Completed/Failed tab.

Up/Down
    Change selected quest.

Mouse
    Click tabs, quests, or close button.

Current limitations
-------------------
- Eight entries per tab; scrolling is still next.
- Controller focus routing is not yet integrated.
- The journal remains an overlay rather than a native inventory module.
