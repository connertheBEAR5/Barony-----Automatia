QUEST MANIFEST AND JOURNAL QUERIES
===================================

Manifest location
-----------------
build/dialogue/quests.json

Alternative packaged location:
data/dialogue/quests.json

Format
------
{
    "version": 1,
    "dialogues": [
        "test",
        "village_blacksmith",
        "swamp_alchemist"
    ]
}

Each entry is a dialogue JSON filename without ".json".

Behavior
--------
The journal attempts to load the manifest once per process. Each listed
dialogue definition is parsed and added to the existing definition
cache.

This means accepted/completed/failed quests can be found by the journal
without requiring the player to reopen the quest-giver NPC.

Invalid dialogue entries are logged and skipped.

Journal query APIs
------------------
getCustomDialogueQuestJournalEntriesByStatus(...)
    Returns only Active, Completed, or Failed entries.

getCustomDialogueQuestJournalCounts(...)
    Returns tab badge/count values.

getCustomDialogueQuestJournalEntry(...)
    Finds one discovered journal entry by quest ID.

The original getCustomDialogueQuestJournalEntries(...) remains the
complete sorted query.

Important
---------
The manifest preloads definitions, not quest progress. Unstarted quests
still stay hidden from the player's journal.
